# NetLookuper

Портативный набор сетевых утилит для Windows: ping, трассировка, DNS (3 вкладки), проверка почтовой
инфраструктуры, проверка веб-сервера и сертификатов, WHOIS. Результат сборки — один автономный `NetLookuper.exe`.

Версия 0.9.2 · © 2026 ln0_kv · лицензия Freeware (текст: `LICENSE.txt`, он же в окне «О программе»).


## Что известно о ограничениях

* Отзыв сертификатов (OCSP/CRL) не проверяется, RBL-списки не проверяются (намеренно).
* DNSSEC: проверяется наличие DNSKEY/DS и признак AD резолвера, полной криптографической валидации нет.
* SMTP-проверка IPv4 и только порт 25; при блокировке порта провайдером результата не будет.
* Системный прокси в Web Check не используется.
